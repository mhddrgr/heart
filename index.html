Heart Disease Prediction Model

A model that estimates whether a patient has heart disease from 13 clinical measurements. It was trained and evaluated on the heart dataset in this project, with duplicate patients removed so that the reported accuracy reflects patients the model has not seen.

The cross-validated figure uses all 302 patients and is the most reliable single estimate. The 61-patient test set is small, so its result carries about ±8 percentage points of uncertainty.

The data

The file heart.csv inside dataset.zip has 1,025 rows, 13 clinical features, and a binary target (1 = heart disease, 0 = no heart disease). There are no missing values.

  • Duplicates: 723 of the 1,025 rows are exact copies of another row. Keeping them would let the same patient appear in both training and testing data, which inflates accuracy. Only the 302 unique rows were kept.
  • Class balance: 164 patients with heart disease and 138 without.
  • Features: age, sex, chest pain type (cp), resting blood pressure (trestbps), cholesterol (chol), fasting blood sugar (fbs), resting ECG (restecg), maximum heart rate (thalach), exercise-induced angina (exang), ST depression (oldpeak), slope (slope), number of major vessels (ca), and thalassemia (thal).

Method

Training and evaluation. The project uses two evaluation steps, and both train and test the model on different patients.

  • Repeated 5-fold cross-validation. The 302 patients are split into five groups. Each group is tested once by a model trained on the other four, and the whole process is repeated three times with different shuffles. Each patient is tested on every repeat.
  • Tuning inside each training fold. Model settings are chosen with a second, inner cross-validation that only sees the training patients. Test patients never influence tuning.
  • Held-out test set. A separate, stratified 80/20 split puts 241 patients into training and 61 into testing. The test patients are scored once, after the model is finished.
  • Final model. The deployed model is retrained on all 302 unique patients using the tuned settings.

Models compared. Logistic regression, a support vector machine (SVM), a random forest, histogram gradient boosting, and a small neural network trained on the GPU with 5 random seeds. The final predictor is an ensemble: the average probability of all five models. The ensemble was defined before any results were seen, so it was not picked for scoring well.

What the numbers mean

The 98% target was not reached, and it could not be reached honestly with this data. Random-split tests on this file report 100% for tree models only because identical copies of a patient land in both training and testing. Those figures measure memorization, not prediction.

With duplicates removed, the best estimate for unseen patients is about 85%, with a plausible range of roughly 83 to 87%.

  • Why the ensemble: it was the most accurate and stable option in cross-validation, and it avoids depending on one model family.
  • Why the GPU was not essential: with 302 patients, the neural network runs fast on a CPU too. It was the weakest individual model, so it does not justify GPU training here.
  • Dataset comparison: a second file, data.zip, has 10,000 records but no detectable signal. Every model scored the majority-class rate of 80% with an AUC near 0.50, meaning the features do not predict its target. It was therefore not used.

Using the model

Score new patients with a CSV file that has the same feature columns as heart.csv:

python predict_heart.py new_patients.csv scored_patients.csv

The output adds risk_probability (0 to 1) and prediction (1 = disease, 0 = no disease, threshold 0.5).

Limitations

  • The dataset is small (302 unique patients) and comes from a single source, so results may not carry over to other hospitals or populations.
  • The held-out test set has only 61 patients, so its accuracy has wide uncertainty.
  • The model is a classroom and research project. It is not a medical device and must not be used to diagnose or treat patients.

Neural network architecture

The neural network is a fully connected network with two hidden layers. Each of the five seeds trains its own copy, and the network's output is the average of the five.

Dots show a sample of units in each layer, not every unit. Every unit in one layer connects to every unit in the next.

  • Input (27 values): the 8 numeric features, standardized to mean 0 and standard deviation 1, plus one-hot columns for the 5 categorical features (4 + 3 + 3 + 5 + 4 = 19 columns).
  • Training: binary cross-entropy loss, AdamW optimizer (learning rate 0.003, weight decay 0.001), 400 full-batch epochs. Each step uses every training patient at once.
  • Seeds: 5 independently initialized networks. Their probabilities are averaged, so one unlucky start cannot dominate.
  • Hardware: the training code uses the NVIDIA GPU (RTX 3060 Ti, 8 GB) through CUDA when it is available. With 302 patients a CPU is just as fast, so the GPU is optional.

The ensemble

Each model gives a probability of heart disease. The final answer is the simple average of the five probabilities (logistic regression, SVM, random forest, gradient boosting, and neural network). Averaging gave the best cross-validated accuracy, and it does not depend on any single model being right.

The model settings were chosen by inner cross-validation, and the ensemble rule was fixed before any results were seen.

Reproduce the project

Put dataset.zip in the same folder as the scripts, then run these commands from that folder. The Python version needs Python 3.11, scikit-learn 1.8, pandas 2.3, numpy, joblib, and PyTorch (CUDA is optional).

python train_heart.py                       # train, evaluate, save heart_model.joblib and results.json
python export_web_model.py                  # write web/model.json for the browser predictor
python predict_heart.py new_patients.csv    # score new patients

train_heart.py (314 lines)
"""
Heart disease classifier for dataset.zip (heart.csv).

Evaluation protocol (chosen to avoid leakage):
- heart.csv has 1,025 rows but only 302 unique patients (723 exact duplicate
  rows). Exact duplicates are removed BEFORE any split, so no patient can be
  in both the training and the test data.
- Outer evaluation: 5-fold stratified CV repeated 3 times. Every repeat puts
  each unique patient in a test fold exactly once.
- Hyperparameters are tuned only inside each outer training fold (nested CV),
  so test labels never influence tuning.
- Ensemble = equal-weight average of all model probabilities. It is fixed in
  advance, not picked by its test score.

Models: logistic regression, SVM, random forest, histogram gradient boosting,
and a small PyTorch MLP (5 seeds, trained on the GPU when one is available).

Usage:
    python train_heart.py                 # evaluate + train final model
    python train_heart.py --repeats 5     # more repeats for tighter estimates
"""

import argparse
import json
import zipfile
from pathlib import Path

import joblib
import numpy as np
import pandas as pd
import torch
from torch import nn
from sklearn.compose import ColumnTransformer
from sklearn.ensemble import HistGradientBoostingClassifier, RandomForestClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, confusion_matrix, roc_auc_score
from sklearn.model_selection import (
    GridSearchCV, RepeatedStratifiedKFold, StratifiedKFold, train_test_split,
)
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.svm import SVC

HERE = Path(__file__).resolve().parent
TARGET = "target"
CATEGORICAL = ["cp", "restecg", "slope", "ca", "thal"]
NUMERIC = ["age", "sex", "trestbps", "chol", "fbs", "thalach", "exang", "oldpeak"]


# ---------- data ----------

def load_data(zip_path: Path):
    """Read heart.csv straight from the zip (no extraction), drop exact duplicates."""
    with zipfile.ZipFile(zip_path) as zf:
        with zf.open("heart.csv") as fh:
            df = pd.read_csv(fh)
    n_raw = len(df)
    df = df.drop_duplicates().reset_index(drop=True)
    X = df.drop(columns=TARGET)
    y = df[TARGET].to_numpy().astype(int)
    return X, y, n_raw


def make_pre():
    return ColumnTransformer([
        ("num", StandardScaler(), NUMERIC),
        ("cat", OneHotEncoder(handle_unknown="ignore", sparse_output=False), CATEGORICAL),
    ])


# ---------- scikit-learn models ----------

def sk_specs(seed):
    def pipe(clf):
        return Pipeline([("pre", make_pre()), ("clf", clf)])

    return {
        "logreg": (
            pipe(LogisticRegression(max_iter=5000)),
            {"clf__C": [0.01, 0.03, 0.1, 0.3, 1, 3, 10]},
        ),
        "svm": (
            pipe(SVC(probability=True, random_state=seed)),
            {"clf__C": [0.1, 0.3, 1, 3, 10], "clf__gamma": ["scale", 0.01, 0.03, 0.1]},
        ),
        "random_forest": (
            pipe(RandomForestClassifier(n_estimators=500, random_state=seed, n_jobs=-1)),
            {
                "clf__max_depth": [None, 4, 8],
                "clf__min_samples_leaf": [1, 2, 4],
                "clf__max_features": ["sqrt", 0.5],
            },
        ),
        "hist_gb": (
            pipe(HistGradientBoostingClassifier(random_state=seed)),
            {
                "clf__learning_rate": [0.03, 0.1],
                "clf__max_depth": [2, 3, None],
                "clf__l2_regularization": [0.0, 1.0],
            },
        ),
    }


def fit_tuned(est, grid, X, y, seed):
    inner = StratifiedKFold(n_splits=5, shuffle=True, random_state=seed)
    gs = GridSearchCV(est, grid, cv=inner, scoring="roc_auc", n_jobs=-1)
    gs.fit(X, y)
    return gs.best_estimator_, gs.best_params_


# ---------- PyTorch MLP (GPU if available) ----------

class MLP(nn.Module):
    def __init__(self, n_in):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(n_in, 32), nn.ReLU(), nn.Dropout(0.3),
            nn.Linear(32, 16), nn.ReLU(), nn.Dropout(0.3),
            nn.Linear(16, 1),
        )

    def forward(self, x):
        return self.net(x).squeeze(1)


def train_mlp(Z, y, seed, device, epochs=400):
    torch.manual_seed(seed)
    model = MLP(Z.shape[1]).to(device)
    opt = torch.optim.AdamW(model.parameters(), lr=3e-3, weight_decay=1e-3)
    loss_fn = nn.BCEWithLogitsLoss()
    zt = torch.tensor(Z, dtype=torch.float32, device=device)
    yt = torch.tensor(y, dtype=torch.float32, device=device)
    model.train()
    for _ in range(epochs):  # full-batch training: the dataset is tiny
        opt.zero_grad(set_to_none=True)
        loss_fn(model(zt), yt).backward()
        opt.step()
    return model.eval()


@torch.no_grad()
def mlp_proba(models, Z, device):
    zt = torch.tensor(Z, dtype=torch.float32, device=device)
    return np.mean([torch.sigmoid(m.to(device)(zt)).cpu().numpy() for m in models], axis=0)


MLP_SEEDS = range(5)


# ---------- evaluation ----------

def evaluate(X, y, device, seed=0, n_repeats=3):
    splitter = RepeatedStratifiedKFold(n_splits=5, n_repeats=n_repeats, random_state=seed)
    specs = sk_specs(seed)
    names = list(specs) + ["mlp"]
    oof = {n: np.zeros((n_repeats, len(y))) for n in names}
    chosen = []

    for i, (tr, te) in enumerate(splitter.split(X, y)):
        rep = i // 5
        X_tr, X_te, y_tr = X.iloc[tr], X.iloc[te], y[tr]

        for name, (est, grid) in specs.items():
            best, params = fit_tuned(est, grid, X_tr, y_tr, seed)
            oof[name][rep, te] = best.predict_proba(X_te)[:, 1]
            chosen.append({"fold": i, "model": name, "params": params})

        pre = make_pre().fit(X_tr)
        Z_tr = pre.transform(X_tr).astype(np.float32)
        Z_te = pre.transform(X_te).astype(np.float32)
        mlps = [train_mlp(Z_tr, y_tr, s, device) for s in MLP_SEEDS]
        oof["mlp"][rep, te] = mlp_proba(mlps, Z_te, device)

        print(f"  outer fold {i + 1}/{5 * n_repeats} done", flush=True)

    oof["ensemble"] = np.mean([oof[n] for n in names], axis=0)
    return oof, chosen


def summarize(oof, y, n_repeats):
    out = {}
    for name, p in oof.items():
        accs = [accuracy_score(y, (p[r] >= 0.5).astype(int)) for r in range(n_repeats)]
        aucs = [roc_auc_score(y, p[r]) for r in range(n_repeats)]
        out[name] = {
            "accuracy_mean": float(np.mean(accs)),
            "accuracy_std": float(np.std(accs)),
            "auc_mean": float(np.mean(aucs)),
            "auc_std": float(np.std(aucs)),
        }
    return out


# ---------- final model ----------

def fit_final(X, y, device, seed=0):
    sk_models, params = {}, {}
    for name, (est, grid) in sk_specs(seed).items():
        best, p = fit_tuned(est, grid, X, y, seed)
        sk_models[name] = best
        params[name] = p

    pre = make_pre().fit(X)
    Z = pre.transform(X).astype(np.float32)
    mlps = [train_mlp(Z, y, s, device) for s in MLP_SEEDS]
    mlp_states = [{k: v.detach().cpu() for k, v in m.state_dict().items()} for m in mlps]

    return {
        "features": list(X.columns),
        "sk_models": sk_models,
        "pre": pre,
        "mlp_states": mlp_states,
        "mlp_n_in": Z.shape[1],
        "params": params,
    }


def predict_proba(artifact, df: pd.DataFrame):
    """Return {model_name: P(heart disease)} for each row of df (CPU inference)."""
    X = df[artifact["features"]]
    probs = {n: m.predict_proba(X)[:, 1] for n, m in artifact["sk_models"].items()}

    Z = artifact["pre"].transform(X).astype(np.float32)
    mlps = []
    for state in artifact["mlp_states"]:
        m = MLP(artifact["mlp_n_in"])
        m.load_state_dict(state)
        mlps.append(m.eval())
    probs["mlp"] = mlp_proba(mlps, Z, "cpu")

    probs["ensemble"] = np.mean([probs[n] for n in list(artifact["sk_models"]) + ["mlp"]], axis=0)
    return probs


def holdout_eval(X, y, device, seed=0, test_size=0.2):
    """Train on 80% of unique patients (tuning included), score once on the untouched 20%."""
    X_tr, X_te, y_tr, y_te = train_test_split(
        X, y, test_size=test_size, stratify=y, random_state=seed)
    artifact = fit_final(X_tr, y_tr, device, seed)
    probs = predict_proba(artifact, X_te)

    results = {}
    for name, p in probs.items():
        pred = (p >= 0.5).astype(int)
        results[name] = {
            "accuracy": float(accuracy_score(y_te, pred)),
            "auc": float(roc_auc_score(y_te, p)),
            "confusion_matrix": confusion_matrix(y_te, pred).tolist(),  # [[TN, FP], [FN, TP]]
        }
    return {
        "n_train": int(len(y_tr)),
        "n_test": int(len(y_te)),
        "results": results,
    }, artifact


# ---------- main ----------

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--data", type=Path, default=HERE / "dataset.zip")
    ap.add_argument("--out", type=Path, default=HERE)
    ap.add_argument("--repeats", type=int, default=3)
    args = ap.parse_args()

    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    dev_name = torch.cuda.get_device_name(0) if device.type == "cuda" else "CPU"
    print(f"Device: {device} ({dev_name})")

    X, y, n_raw = load_data(args.data)
    print(f"Raw rows: {n_raw} | unique patients used: {len(y)} | positives: {int(y.sum())}")

    print("Evaluating (nested CV, duplicate-free):")
    oof, chosen = evaluate(X, y, device, n_repeats=args.repeats)
    summary = summarize(oof, y, args.repeats)

    print("\nHeld-out results (mean ± std over repeats):")
    for name, s in summary.items():
        print(f"  {name:14s} acc {s['accuracy_mean'] * 100:6.2f}% ± {s['accuracy_std'] * 100:4.2f}"
              f"   AUC {s['auc_mean']:.3f} ± {s['auc_std']:.3f}")

    print("\nHold-out test (stratified 80/20 split; test patients never used for training or tuning):")
    holdout, _ = holdout_eval(X, y, device)
    print(f"  train patients: {holdout['n_train']} | test patients: {holdout['n_test']}")
    for name, r in holdout["results"].items():
        print(f"  {name:14s} acc {r['accuracy'] * 100:6.2f}%   AUC {r['auc']:.3f}")

    cm_cv = confusion_matrix(y, (oof["ensemble"][0] >= 0.5).astype(int)).tolist()

    print("\nTraining final model on all unique patients...")
    artifact = fit_final(X, y, device)
    print("Tuned hyperparameters (final fit):")
    for name, p in artifact["params"].items():
        print(f"  {name}: {p}")

    args.out.mkdir(parents=True, exist_ok=True)
    joblib.dump(artifact, args.out / "heart_model.joblib")
    (args.out / "results.json").write_text(json.dumps({
        "raw_rows": n_raw,
        "unique_patients": int(len(y)),
        "repeats": args.repeats,
        "summary": summary,
        "confusion_matrix_ensemble_cv": cm_cv,
        "holdout": holdout,
        "final_params": artifact["params"],
        "outer_fold_params": chosen,
    }, indent=2, default=str))
    print(f"\nSaved: {args.out / 'heart_model.joblib'}")
    print(f"Saved: {args.out / 'results.json'}")


if __name__ == "__main__":
    main()
export_web_model.py (127 lines)
"""
Export the trained heart model to web/model.json so it can run in a web browser.

The browser predictor (web/heart_model.js) rebuilds the same ensemble as
predict_proba() in train_heart.py: scaling and one-hot encoding, logistic
regression, RBF SVM with Platt scaling, random forest, histogram gradient
boosting, and the 5-seed neural network, averaged with equal weights.

Usage (after train_heart.py has written heart_model.joblib):
    python export_web_model.py [reference_predictions.json]

The optional second argument writes Python predictions for every unique
patient. web/heart_model.js is checked against these numbers.
"""

import json
import sys
from pathlib import Path

import joblib
import numpy as np

from train_heart import HERE, CATEGORICAL, NUMERIC, load_data, predict_proba


def tree_to_dict(sk_tree):
    t = sk_tree.tree_
    value = t.value[:, 0, :]
    value = value / value.sum(axis=1, keepdims=True)  # class fractions per node
    return {
        "l": t.children_left.tolist(),
        "r": t.children_right.tolist(),
        "f": t.feature.tolist(),
        "t": t.threshold.tolist(),
        "p": value[:, 1].tolist(),  # probability of class 1 (heart disease)
    }


def export_random_forest(clf):
    return {"trees": [tree_to_dict(est) for est in clf.estimators_]}


def export_hist_gb(clf):
    trees = []
    for stage in clf._predictors:
        nodes = stage[0].nodes
        trees.append({
            "leaf": nodes["is_leaf"].astype(int).tolist(),
            "f": nodes["feature_idx"].astype(int).tolist(),
            "t": nodes["num_threshold"].astype(float).tolist(),
            "l": nodes["left"].astype(int).tolist(),
            "r": nodes["right"].astype(int).tolist(),
            "v": nodes["value"].astype(float).tolist(),
            "ml": nodes["missing_go_to_left"].astype(int).tolist(),
        })
    return {"baseline": float(clf._baseline_prediction.ravel()[0]), "trees": trees}


def export_svm(clf):
    return {
        "sv": clf.support_vectors_.tolist(),
        "dual": clf.dual_coef_[0].tolist(),
        "b": float(clf.intercept_[0]),
        "gamma": float(clf._gamma),
        "A": float(clf.probA_[0]),
        "B": float(clf.probB_[0]),
    }


def export_logreg(clf):
    return {"coef": clf.coef_[0].tolist(), "b": float(clf.intercept_[0])}


def export_mlp(states):
    seeds = []
    for st in states:
        layers = []
        for idx in ("0", "3", "6"):  # Linear layers in nn.Sequential
            layers.append({
                "W": st[f"net.{idx}.weight"].numpy().tolist(),
                "b": st[f"net.{idx}.bias"].numpy().tolist(),
            })
        seeds.append(layers)
    return {"seeds": seeds}


def main():
    artifact = joblib.load(HERE / "heart_model.joblib")
    pre = artifact["pre"]
    num = pre.named_transformers_["num"]
    cat = pre.named_transformers_["cat"]
    sk = artifact["sk_models"]

    model = {
        "version": 1,
        "features": artifact["features"],
        "numeric": NUMERIC,
        "categorical": CATEGORICAL,
        "scaler_mean": num.mean_.tolist(),
        "scaler_scale": num.scale_.tolist(),
        "categories": {name: [int(c) for c in cats]
                       for name, cats in zip(CATEGORICAL, cat.categories_)},
        "logreg": export_logreg(sk["logreg"].named_steps["clf"]),
        "svm": export_svm(sk["svm"].named_steps["clf"]),
        "random_forest": export_random_forest(sk["random_forest"].named_steps["clf"]),
        "hist_gb": export_hist_gb(sk["hist_gb"].named_steps["clf"]),
        "mlp": export_mlp(artifact["mlp_states"]),
    }

Score patients with the trained heart disease model.

Usage:
    python predict_heart.py <input.csv> [output.csv]

The input CSV needs the same feature columns as heart.csv (age, sex, cp, trestbps,
chol, fbs, restecg, thalach, exang, oldpeak, slope, ca, thal). A "target" column
is optional and ignored. The output adds:
    risk_probability  - ensemble probability of heart disease (0 to 1)
    prediction        - 1 = heart disease predicted, 0 = no heart disease (threshold 0.5)
"""

import sys
from pathlib import Path

import joblib
import pandas as pd

from train_heart import HERE, predict_proba


def main():
    if len(sys.argv) < 2:
        print(__doc__)
        sys.exit(1)

    inp = Path(sys.argv[1])
    out = Path(sys.argv[2]) if len(sys.argv) > 2 else inp.with_name(inp.stem + "_predictions.csv")

    artifact = joblib.load(HERE / "heart_model.joblib")
    df = pd.read_csv(inp)

    missing = [c for c in artifact["features"] if c not in df.columns]
    if missing:
        sys.exit(f"Input is missing required columns: {missing}")

    probs = predict_proba(artifact, df)
    result = df.copy()
    result["risk_probability"] = probs["ensemble"].round(4)
    result["prediction"] = (probs["ensemble"] >= 0.5).astype(int)
    result.to_csv(out, index=False)

    print(f"Scored {len(result)} patients -> {out}")
    print(f"Predicted heart disease: {int(result['prediction'].sum())} of {len(result)}")

/*
 * Browser version of the heart disease ensemble (no Python needed).
 * Reproduces predict_proba() from train_heart.py using model.json, which is
 * written by export_web_model.py. The ensemble is the equal-weight average of:
 *   logistic regression, RBF SVM (Platt scaling), random forest,
 *   histogram gradient boosting, and a 5-seed neural network.
 */
(function (root) {
  "use strict";

  // Feature preprocessing: standardize numeric columns, one-hot encode categoricals.
  function preprocess(model, row) {
    const z = [];
    model.numeric.forEach((name, i) => {
      z.push((Number(row[name]) - model.scaler_mean[i]) / model.scaler_scale[i]);
    });
    model.categorical.forEach((name) => {
      const value = Number(row[name]);
      model.categories[name].forEach((c) => z.push(value === c ? 1 : 0));
    });
    return z;
  }

  function sigmoid(x) {
    return x >= 0 ? 1 / (1 + Math.exp(-x)) : Math.exp(x) / (1 + Math.exp(x));
  }

  function logregProba(m, z) {
    let s = m.b;
    for (let i = 0; i < z.length; i++) s += m.coef[i] * z[i];
    return sigmoid(s);
  }

  // libsvm Platt scaling: P = 1 / (1 + exp(A*f + B)), written in a stable form.
  function svmProba(m, z) {
    let f = m.b;
    for (let i = 0; i < m.sv.length; i++) {
      let d2 = 0;
      const sv = m.sv[i];
      for (let j = 0; j < z.length; j++) {
        const diff = z[j] - sv[j];
        d2 += diff * diff;
      }
      f += m.dual[i] * Math.exp(-m.gamma * d2);
    }
    const fApB = m.A * f + m.B;
    return fApB >= 0 ? Math.exp(-fApB) / (1 + Math.exp(-fApB)) : 1 / (1 + Math.exp(fApB));
  }

  function treeLeafValue(t, z, getNext) {
    let node = 0;
    while (t.l[node] !== -1) node = getNext(t, node, z);
    return node;
  }

  function forestProba(m, z) {
    let total = 0;
    m.trees.forEach((t) => {
      // scikit-learn trees compare float32 inputs, so round the same way.
      const leaf = treeLeafValue(t, z, (tree, node, x) =>
        Math.fround(x[tree.f[node]]) <= tree.t[node] ? tree.l[node] : tree.r[node]);
      total += t.p[leaf];
    });
    return total / m.trees.length;
  }

  function histGbProba(m, z) {
    let raw = m.baseline;
    m.trees.forEach((t) => {
      let node = 0;
      while (!t.leaf[node]) {
        const x = z[t.f[node]];
        let goLeft;
        if (Number.isNaN(x)) goLeft = t.ml[node] === 1;
        else goLeft = x <= t.t[node];
        node = goLeft ? t.l[node] : t.r[node];
      }
      raw += t.v[node];
    });
    return sigmoid(raw);
  }

  function mlpSeedProba(layers, z) {
    let h = z;
    layers.forEach((layer, idx) => {
      const out = layer.b.map((bias, o) => {
        let s = bias;
        const row = layer.W[o];
        for (let i = 0; i < h.length; i++) s += row[i] * h[i];
        return s;
      });
      h = idx < layers.length - 1 ? out.map((v) => (v > 0 ? v : 0)) : out;
    });
    return sigmoid(h[0]);
  }

  function mlpProba(m, z) {
    const probs = m.seeds.map((layers) => mlpSeedProba(layers, z));
    return probs.reduce((a, b) => a + b, 0) / probs.length;
  }

  // Returns probabilities of heart disease for one patient.
  function predict(model, row) {
    const z = preprocess(model, row);
    const out = {
      logreg: logregProba(model.logreg, z),
      svm: svmProba(model.svm, z),
      random_forest: forestProba(model.random_forest, z),
      hist_gb: histGbProba(model.hist_gb, z),
      mlp: mlpProba(model.mlp, z),
    };
    const values = Object.values(out);
    out.ensemble = values.reduce((a, b) => a + b, 0) / values.length;
    return out;
  }

  const api = { predict, preprocess };
  if (typeof module !== "undefined" && module.exports) module.exports = api;
  else root.HeartModel = api;
})(typeof self !== "undefined" ? self : this);
