What the project did

  1. 1. Cleaned the data.The file had 1,025 rows, but 723 were exact copies. Keeping copies would let the model see the same patient twice and look better than it is.
  2. 2. Trained five different models.Logistic regression, a support vector machine, a random forest, gradient boosting, and a neural network. Each one learns patterns from patients whose outcome is known.
  3. 3. Averaged them.The final answer is the average of the five. In cross-validation, averaging was more accurate than any single model.
  4. 4. Tested on unseen patients.Each patient was held out while the model learned, then used to check the model. This is what makes the accuracy trustworthy.

The neural network in simple words

Think of the neural network as a team of simple calculators stacked in layers. Each calculator looks at numbers from the layer before it, decides how much each one matters, and passes a result forward. The first layer picks up simple patterns, and the next layer combines them into more complicated ones.

Learning works like practice with feedback:

  1. It makes a guess for a patient.
  2. It compares the guess with the known answer and measures how wrong it was.
  3. It adjusts its internal settings slightly so the next guess is a little better.
  4. It repeats this many times over all the training patients.

Our network has about 1,400 adjustable settings. With only 302 patients, a simpler model did slightly better on its own, so the final answer uses the average of all five models.

Why not 98%?

Some tests on this file showed 100% accuracy. Those numbers were misleading: copies of the same patient landed in both the training and testing sets, so the model was partly tested on patients it had already seen. Once the copies were removed, the honest accuracy was about 85%. We report that number.

How to use it

  • Try it online: open the Predict page, enter a patient's measurements or pick one of the four examples, and press Predict.
  • Read the details: the Report page has the method, results, neural network diagram, and source code.
  • Use it in Python: the Download page has the trained model and the scripts. Run python predict_heart.py new_patients.csv to score a file of patients.

Limits to mention

  • The data comes from 302 patients from one source, so results may not carry over to other groups.
  • The separate test set has only 61 patients, so its result could easily be a few points higher or lower.
  • It is not a medical tool. It must not be used to diagnose or treat anyone.

A 60-second explanation for class

"The model predicts heart disease from 13 measurements. I removed 723 duplicate rows so no patient was counted twice. I trained five models and averaged them. The neural network is a stack of simple calculators that learns by guessing, checking its error, and adjusting. It reached about 85% accuracy on patients it had never seen. That is lower than 98%, but 98% was only possible because of duplicates, so the honest result is the one I'm reporting."
