Download

The trained model and the Python scripts. The browser predictor on the Predict page uses model.json, which is also linked here.

heart_model.joblib

The trained model for Python (2.3 MB).

model.json

The same model in browser-readable form (1.1 MB).

predict_heart.py

Scores a CSV of patients and flags rows with bad values.

train_heart.py

Trains and evaluates the model.

export_web_model.py

Exports the model to model.json for the browser.

test_heart.py

Automated checks. Run them with the command below.

requirements.txt

The exact library versions the model was built with.

results.json

All metrics and the tuned settings for each fold.

Run it in Python

Install the libraries, then score a file of patients. The CSV needs the 13 feature columns from heart.csv.

pip install -r requirements.txt
python predict_heart.py new_patients.csv
python -m unittest test_heart -v

To retrain, put dataset.zip (containing heart.csv) in the same folder and run python train_heart.py.
