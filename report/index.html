Heart Disease Prediction: Model Report

The model estimates heart disease risk from 13 clinical measurements. Every result below is measured on patients the model did not learn from.

1. The data

  • The dataset has 1,025 rows, 13 clinical measurements per row, and a yes/no outcome for heart disease.
  • 723 rows were exact copies of other rows. Only the 302 unique patients were kept, so no patient is counted twice.
  • Outcome balance: 164 patients with heart disease, 138 without.

2. How the model was tested

  • Repeated cross-validation: the patients are split into 5 groups. Each group is tested by a model trained on the other 4. The process repeats 3 times, so every patient is tested 3 times.
  • Tuning on training data only: each model's settings are chosen using only the training patients, so the test patients never influence them.
  • Separate test set: 61 patients (20%) were held out from the start and used once, after the models were finished.
  • Final model: retrained on all 302 unique patients for the predictor and the downloads.
  • Ensemble: the average of five models' probabilities. This rule was fixed before any results were seen.

Why the ensemble? It was chosen before the results were known, and it has the highest cross-validated accuracy. The ensemble combines five different approaches, so it does not rely on any one of them.

4. The neural network

The neural network is one of the five models. It has two hidden layers of simple calculators (called units). Each unit combines the inputs with its own adjustable weights, then passes the result forward.

Total per network1,441

How it learns

  1. Predict: it makes a guess for each training patient.
  2. Measure the error: it compares the guess with the known outcome.
  3. Adjust: it changes its 1,441 settings slightly to reduce the error. This is called backpropagation.
  4. Repeat: it repeats these steps 400 times.

During training, 30% of the units are switched off at random at each step (dropout). This stops the network from relying on any single unit. Five networks are trained from different random starting points, and their predictions are averaged.

On this small dataset the network scored lower than logistic regression, because it has far more adjustable settings than 302 patients can support. Neural networks usually do better with much more data.

5. Limitations

  • The data comes from 302 patients from a single source. Results may not apply to other groups.
  • The test set has only 61 patients, so its accuracy could be a few points higher or lower on other patients.
  • The thalassemia codes follow the common version of this dataset.
  • This is a student project. It is not a medical tool and must not be used to diagnose or treat anyone.
